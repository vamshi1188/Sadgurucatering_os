# v1.0.3.10 — Health Endpoint

## Objective

Create the first permanent API endpoint for Sadguru Catering OS.

The endpoint provides a lightweight application health signal that
can later be consumed by Docker, cloud infrastructure, load balancers,
monitoring systems, and deployment systems.

## Endpoint

### Method

GET

### Path

`/api/v1/health`

### Success Response

HTTP status:

`200 OK`

Response:

```json
{
  "status": "ok"
}
