# v1.0.4.6 — API Client Layer

## Objective

Establish a centralized frontend API client using the configured backend API
base URL.

## Scope

- Centralize HTTP request handling
- Use `VITE_API_BASE_URL`
- Provide typed GET requests
- Provide typed POST requests
- Establish API error handling
- Add API client tests

## Implementation

- Added `frontend/src/api/client.ts`
- Added `ApiError`
- Added `apiClient.get<T>()`
- Added `apiClient.post<T>()`
- Updated `frontend/src/api/index.ts`
- Added API client tests
- Configured the Vitest environment with the API base URL

## Error Handling

Non-2xx responses throw `ApiError` containing:

- HTTP status code
- Standardized request failure message
