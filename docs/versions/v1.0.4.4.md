# v1.0.4.4 — Application Entry Point & Global App Shell

## Objective

Establish the frontend application entry point and global provider composition
for Sadguru Catering OS.

## Scope

- Establish the application root under `src/app`
- Configure the React application entry point
- Add TanStack Query provider
- Establish the global provider composition pattern
- Add an application rendering test

## Implementation

- Added `src/app/App.tsx`
- Added `src/app/providers.tsx`
- Updated `src/main.tsx` to render the application shell
- Added `src/app/App.test.tsx`
- Added Vitest/jsdom configuration required for the application render test
- Registered Testing Library DOM matchers
- Configured a shared TanStack Query client

## Provider Configuration

The application currently uses:

- `QueryClient`
- `QueryClientProvider`

Configured query defaults:

- Retry failed queries once
- Disable refetch-on-window-focus

Future provider slots are intentionally deferred to later versions.

`vite.config` without a file extension under the planned native config loader.
This does not affect the current build or test results.

## Known Limitations

testing foundation are intentionally deferred to their respective micro-versions.
