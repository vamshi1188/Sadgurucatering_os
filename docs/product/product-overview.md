# Sadguru Catering OS — Product Overview

## Product Name

Sadguru Catering OS

## Purpose

Internal business operating system for Sadguru Catering.

## Primary Objective

Centralize the company's business operations into one integrated
software platform.

## Initial Users

Fewer than 10 internal company users.

## Primary Users

- Owner
- Manager
- Sales
- Accounts
- Kitchen
- Inventory
- Operations
- Administration

## Core Business Lifecycle

Lead
→ Customer
→ Quotation
→ Confirmed Event / Order
→ Menu
→ Recipe
→ Ingredient Requirement
→ Procurement
→ Inventory
→ Kitchen Production
→ Staff
→ Logistics
→ Event / Delivery
→ Payment
→ Expense
→ Profitability
→ Feedback
→ Repeat Business

## Product Philosophy

The system should maintain a single source of truth for business
operations and minimize duplicate data entry.

## Architecture Direction

Modular monolith.

## Technology Direction

Backend: Go

Frontend: React + TypeScript

Database: PostgreSQL

Deployment: Docker

Cache: Redis where justified

Object Storage: Documents and images

## Current Status

Project initialization.
